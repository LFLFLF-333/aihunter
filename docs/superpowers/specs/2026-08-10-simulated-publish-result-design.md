# 模拟发布结果展示设计

## 目标

在 AI 情报员网页的交互演示中补全“审批后发布结果”环节，让访客看到 Agent 在飞书群内发布后的真实呈现，同时不产生任何真实消息、API 调用或数据访问。

## 已确认方案

- 保留现有“模拟发布完成”状态和“重新体验”入口。
- 在成功提示下方新增“群内发布结果（真实案例脱敏展示）”。
- 使用用户提供的飞书群发布截图作为历史真实运行案例。
- 截图在桌面端完整展示，在移动端按容器宽度缩放，不产生横向溢出。
- 点击截图可查看大图；大图支持显式关闭，并可通过 Escape 键关闭。
- 截图附近必须注明：图片是历史真实运行截图，本次网页体验不会发送消息或调用 API。

## 组件与数据流

发布结果只在演示状态进入 `simulated-published` 后显示。截图作为本地静态资源随网站打包，不连接飞书，也不请求外部服务。图片放大状态仅存在于浏览器内存中，刷新后清除。

## 异常与无障碍

- 图片必须提供准确的替代文本。
- 放大层必须有可识别的关闭按钮、对话框语义和键盘关闭能力。
- 若图片加载失败，页面仍保留发布完成说明和安全边界文字。

## 验收标准

1. 未完成模拟审批前，不显示群内发布截图。
2. 点击“模拟确认发布”后，同时显示完成提示、真实性说明和发布结果截图。
3. 点击截图可放大，点击关闭按钮或按 Escape 可退出。
4. 桌面端和移动端均无横向溢出。
5. 自动化测试与生产构建通过。

## 范围外

- 不连接真实 Hermes Agent。
- 不调用飞书 API。
- 不允许访客触发真实群消息。
- 不修改 Agent Profile、工作流或飞书 Bot 配置。
